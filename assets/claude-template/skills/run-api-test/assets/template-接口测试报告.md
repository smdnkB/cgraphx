# 接口测试报告模板

适用于 `run-api-test` skill 在 R5 生成。默认输出到 `docs/features/<feature-id>/<文件前缀>-接口测试报告.md`。

本模板由 skill 在 R5 填充:汇总 + 逐接口结果 + 失败原因分类 + 下一步建议。

## 核心设计原则

**不是每个场景都需要详细展示。** 按接口聚合，同接口内区分：

| 展示级别 | 适用场景 | 内容 |
|---|---|---|
| **详细展示** | 主场景（正常流程）、涉及业务规则的异常/边界 | 入参 + 请求/响应 + 断言判定 + DB 核实 |
| **简单展示** | 简单边界（空值/格式错误/越权等不涉及业务规则） | 状态 + 耗时 + 失败原因（如有） |

**一个接口最多 2 个详细展示的场景。**

## 完整结构

```markdown
# 接口测试报告:<feature 标题>

> feature-id: <feature-id>
> 生成时间: <YYYY-MM-DD HH:MM>

> 关联 .bru 集合: docs/bruno/<服务>/<需求前缀>/

## 填写说明

| 场景类型 | 展示级别 | 说明 |
|---|---|---|
| **主场景（正常流程）** | 详细 | 核心业务路径，必须详细记录 |
| **涉及业务规则的异常/边界** | 详细 | 如：库存不足、余额不足、状态机流转等 |

| **失败场景** | 详细 | 无论类型，失败场景必须详细展示 |
