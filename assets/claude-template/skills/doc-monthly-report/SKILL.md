# 月底日报汇总 (doc-monthly-report)

## 定位

每月底要填「月底日报」表单,每天一行、≤100 字。日常日报已经在工作台逐个填过;本 skill 拉全月记录,按日聚合并浓缩成可直接粘贴的表。

只输出到会话,不写文件、不归档。只生成可粘贴的表,不自动提交工作台的月报表单。

与 `doc-report` 的月报区分:`doc-report` 从 cgraphx 时间线出工作汇报;本 skill 从工作台日报出月底填报表。

## 1. 确认参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 月份 | 当月 | `YYYY-MM` |
| 工作台地址 | 无,必问 | trycloudflare 临时隧道,每月可能更换 |
| 登录账号 | 无,必问 | 同时是查询的 userName;也可用 `WORK_REPORT_USER` |
| 填写人 | 同登录账号 | 查别人时加 `--filler` |
| 密码 | 无 | `WORK_REPORT_PASS`,或终端隐藏输入;不接受 `--password` |

凭证规则:密码不写进任何文件,不放进命令行,不贴在对话里。优先让用户在终端执行下面命令,脚本会关回显读密码,输出直接回到会话;用户已在 shell 设了 `WORK_REPORT_PASS` 时,agent 可直接跑。

```bash
node <skill-dir>/scripts/fetch-reports.mjs \
  --base https://<当前隧道域名>/api \
  --month 2026-10 --user <登录账号>
```

地址过期判断:登录阶段 DNS 失败 / 非 JSON / 连接失败 → 先怀疑隧道地址已更换,向用户要新地址,不反复重试;拉取阶段 `{"error":"未登录"}` → 先查 token/Authorization,再怀疑地址。

## 2. 拉数据

- 脚本按接口 `total` 自动翻页,一个月正常 ≤60 条。
- 校验输出头部「共 N 条,覆盖 M 个工作日」;仍打出「拉取不完整」时不出表,缩小范围或重跑。
- 当月没有记录 → 直接提示,不生成空表。

## 3. 语义浓缩(每行 ≤100 字)

对每个日期,把当日多条记录(workType / project / content)合并浓缩成一行:

- 保留主线交付和关键量化数字(场景数、接口数、commit 数、性能前后值);
- 同日多条同类记录去重合并(发版、配合取数等运维短条目可并入句尾);
- 相邻两天内容完全相同时各自保留一行,措辞按当天侧重微调;
- 「请假」「配合取数」「协助排查」等短条目如实保留,不虚构扩充;
- 严格依据拉到的 content,不得编造记录里没有的工作。

## 4. 输出

Markdown 表,日期列 `M.DD`(月不补零、日补两位):

```markdown
| 日期 | 工作内容 |
|------|---------|
| 10.03 | 完成订单导出后台任务与接口,联调站内通知,自测 4 个边界场景 |
| 10.04 | 请假 |
```

表后附「未列入」:

- 周末无记录 → 列出具体日期,标「周末休息」;表单要求每个自然日都填时,在表中补「周末休息」行;
- 工作日无记录 → 标「未填报」;
- 月末最后一天尚未填报 → 标「待填」;
- 周末有记录 → 照常列入,不要漏掉。

只在会话里输出;不写文件、不归档。

## 5. 收尾

- 月末最后一天还没填 → 提醒先去工作台补填,再重跑;
- 某天粒度要调整(更短/更长)→ 用户点名日期后重写该行;
- 需要 Excel → 用户自己把 Markdown 表粘进 Excel。

## 已知坑

- WebFetch 拉不了该隧道域名,直接用脚本/curl。
- 手动复制 token 到 shell 容易抄错,脚本内部自行登录换 token。
- 出现 `{"error":"未登录"}` = Authorization 头没带或 token 错,先检查脚本,再怀疑地址。
- 法定节假日不识别(只按周末);节假日无记录会落在「未填报」,需手动改。
