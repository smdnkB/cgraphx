交互说明

  1. ① 侧栏第 5 个入口「开发任务」,沿用既有应用壳
  2. ② 按最近活动倒序;从未绑定过会话的任务排最后,数字列显示「—」
  3. ③ 点任务名 → 任务详情。「进行中」= 存在未结束的绑定(任意会话)
  4. ④ web 不请求外部接口;页面无刷新、绑定、新建等任何写操作
  5. 状态切换:空态 = 一个任务都没有;异常 = 项目没装 task
  1. ⑤ 关联需求目录只显示路径,不可点
  2. ⑥ 会话数按不同会话去重(本例 1 个会话、2 段绑定);时长为各段之和
  3. ⑦ 产出按类别分组,只列现存文件;知识库、系统地图(code-map)、模型知识库(schema-knowledge)可点跳转,其余只显示路径;代码默认收起
  4. ⑧ 一条绑定一块(同一会话绑定两段 → 两块,各带绑定来源);事件默认折叠;展开后按轮次分组,行样式同时间线页;不跳时间线
  5. ⑨ 每个会话块最多 500 条事件
  6. ⑩ 参考:范围限知识库 / 代码地图(含 design-map)/ 数据库结构 / 需求文档,不列代码;命令里出现路径 ≠ 一定读过,故标「推断」;已在产出栏的文件不重复;链接规则同产出
  7. 状态切换:空态 = 任务从未绑定会话;异常 = 任务 id 不存在
