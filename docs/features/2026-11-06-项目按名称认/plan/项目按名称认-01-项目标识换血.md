### T-1: 项目标识换血——只按名称认

- 目标: 把项目标识从「origin + name 两项」换成只有 `name`;`identity.json` 升到版本 2(带 `origins`);项目目录名就是名字;sessions.db 的删项目记录与开始目录归属改用名字、`start_dirs` 不再写 origin、新增 `dirs_checked` 表;`install` 一律问名字并写回。本任务只做形状、认法与存储,**不做**重名提示(T-2)和补录的现认 / 重建跳过(T-3)。
- 对应 spec 编号: D1、D2、D3;D4 的键与列部分(removed_projects 键、start_dirs 不写 origin);D6;D7 的建表部分;D8 的存储部分;K1、K2、K3、K5 里与键有关的部分
- 强制引用: `docs/guides/coding-standards.md` 的「边界与结构」「选型」「错误与日志」;`docs/guides/interface-standards.md` 的「输出」(`project show` / `list` 的文本与 `--json` 形态);`docs/guides/data-standards.md` 的「DDL 层」「Schema 变更约定」(spec 全局约束:`sessions.db` 不走目标项目的 Schema 变更约定,建表仍用幂等 `CREATE TABLE IF NOT EXISTS`)
- 涉及范围(12 个文件):
  - `src/core/project-identity.ts`
  - `src/core/user-data-dir.ts`
  - `src/core/session-index.ts`
  - `src/core/repo-projects.ts`
  - `src/core/project/index.ts`
  - `src/core/project/types.ts`
  - `src/core/project/show.ts`
  - `src/core/project/list.ts`
  - `src/core/project/cli.ts`
  - `src/core/project/name.ts`
  - `src/cli/installer/project-steps.ts`
  - `src/core/timeline/ingest/ingest.ts`(只改 `DirClassification` 与 `classifyStartDir` 里 origin 的读写)
- 必须严格执行:
  - C-1(项目标识与根标识的形状)、C-2(默认名字来源顺序)、C-3(identity.json 版本 2 与读写 API)、C-4(项目目录命名与查找)、C-5(sessions.db 合同)、C-11(project 命令输出形态与改名提示)
  - 契约里的类型名、字段名、函数名、方法名、表名、列名一律不改
  - 地址(`origin`)只用于 C-2 取默认名字和往 `RootIdentity.origin` 上带,不参与任何项目是否相同的比较
  - 注释里出现的旧概念(`needsName`、`identityKind`、「origin 加名字」、「按 origin 或名称」)一并清掉——完成条件的 grep 会按注释也查
- 允许局部适配:
  - 内部辅助函数的拆分与命名、局部变量名、注释措辞
  - 现有报错 / 提示文案里契约没钉死的措辞
- 具体要求:

  **1. `src/core/project-identity.ts`**
  - 重写文件头注释:身份来源表改成「记下的名字 / 工作区根有 origin 取仓库名 / 装过取目录名(子目录项目取子目录名)/ 没有标识」;写明 `origin` 只给默认名字和重名判断用,不参与比较。
  - 按 C-1 改类型与函数:`ProjectIdentity` 只留 `name`;`RootIdentity` 增加 `origin`、删除 `needsName`;删除 `IdentityKind` 与 `identityKind`;`sameIdentity` 只比名字;`projectDisplayName` 返回名字;`rememberRootIdentity` 增加 `origin` 参数。
  - 按 C-2 改 `readRootIdentity`:记下的名字 → 工作区根有 origin 取仓库名(只对 `subdir === null`;取规整后 origin 的最后一段,过 `validateProjectName`,不过就往下走)→ 装过取默认名字(目录名 / 子目录最后一段)→ 没有标识。每一步都把 origin 带出。
  - `defaultIdentity` 改为带 origin 参数;`rememberedRoot` 增加 origin;`identityOfRoot` 的返回带上 origin;`git-error` 仍不进记忆。
  - 进程内记忆的行为保持不变:`writeProjectName` 写完清这个根的记忆。
  - `normalizeOrigin`、`parseGitConfig`、`applyInsteadOf`、`readGitConfig`、`validateProjectName`、`defaultProjectName` 不动。
  - 检查 `src/core/` 里没有循环依赖:本文件继续只 import `data-location`、`directory` 两个基础层模块。

  **2. `src/core/user-data-dir.ts`**
  - 按 C-3 改 `IDENTITY_VERSION`、`readIdentityFile`(返回 `ProjectDirIdentity`)、`writeIdentityFile`(新格式)、新增 `appendProjectOrigin`。
  - 按 C-4 改 `projectDirBaseName`(只取 `id.name` 处理)、`findProjectDir`、`ownedDir`(按名字比)、`ProjectDirEntry.identity` 类型。
  - `ensureProjectDir` 写目录时用新格式(`origins: []`)。
  - 文件头注释里「项目目录名按标识取」改成「按名字取」。
  - 保持:临时目录 + rename 建目录、`-2`/`-3` 撞号、0700 权限、过期临时目录清理。

  **3. `src/core/session-index.ts`**

  - 文件头注释「四表」改五表并补 `dirs_checked` 一句。
  - `openSessionIndex` 的建表、0600、30 天清理逻辑不变。

  **4. `src/core/repo-projects.ts`**

  **5. `src/core/project/types.ts`**
