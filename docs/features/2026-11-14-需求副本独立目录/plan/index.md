# 需求副本独立目录实现计划

> 产物: plan

## 设计预览
新建的需求 worktree 放在 `~/.cgraphx/worktrees/<项目标识>/<主目录名>@<需求前缀>`，与 `projects/` 项目数据目录分开；项目标识由主目录真实路径确定，避免同名仓库互相占用。需求分支仍属于主仓库。旧的主目录同级副本不搬迁，继续支持查看、合入、删除与重新接回分支。不得移动或清理已有真实副本。

## 实施顺序
1. 统一生成新副本路径，保持登记名称和 shared 链接协议；前置检查后创建父目录，维持失败回滚。
2. 删除时只接受当前项目的新路径或旧的同级路径，继续核对 shared 链接、Git worktree 和未提交改动；拒绝登记被篡改或跨项目路径。
3. 更新 CLI 和内置 skill 的位置说明及示例，实际操作使用 CLI 返回的路径。
4. 验证新旧副本生命周期、同名项目隔离、删除保护、重接分支、失败回滚及现有功能；运行构建和适当测试。

## 查缺与验收
- 注册表、会话归属、项目根定位沿用绝对路径与原副本名称；新旧路径都可识别。
- 不将工作目录置于可被项目数据清理递归删除的 `projects/` 下；项目重名或改名不影响其他主目录。
- 路径由主目录真实路径稳定生成；异常、目标占用与脏工作区不可覆盖或误删。
- `~/.cgraphx` 不可写时创建失败并给出错误；其他现有项目文件不变。
- 遵循 `docs/guides/coding-standards.md`、`docs/guides/interface-standards.md`。
