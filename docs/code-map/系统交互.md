## 一句话

cgraphx 是本地 CLI + 本地 web:被 Claude Code 的 hook、git 的 post-commit 钩子和 agent 调用,读写项目内的 SQLite 与 markdown 文件,并只读调用本机 git;对外只有四类连接——只读查业务库、经 HTTP 只读查询接口查库、npm 自更新,以及浏览器从公网加载字体和画图组件。
