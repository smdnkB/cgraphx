## 一句话

浏览器打开 `/map/flow/<流程名>` 时,web 现读 `docs/code-map/` 下的视图文件、现跑 `git diff` 判断是否过期、查知识库索引判断概念能否点击,输出带 mermaid 原文的页面;浏览器再按需从 jsDelivr 加载画图组件把原文画成图,加载不到就保留原文。知识库条目页反过来按概念列出相关视图。
